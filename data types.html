What is Data Types

In C++ data types specify the type and size of a variable can hold. Every variable must be
declared with a specific data type so the compiler knows how much memory to allocate
and how to interpret its value.
C++ data types are broadly classified into three main categories:
Fundamental (Built-in), Derived and User-Defined .


1.Fundamental Data Types (Built-in)

;
Data Type Group Keyword Typical Size Description Example
Integer int 4 bytes Stores whole numbers without decimals. int age = 25;
Floating-Point float 4 bytes Stores fractional numbers (6-7 decimal digits precision). float pi = 3.14;
Double Floating-Point double 8 bytes High-precision decimal numbers (15 decimal digit). double balance = 945.12;
Character char 1 byte Stores a single character enclosed in single quotes. char grade 'A';
Boolean bool 1 byte Stores logical states: true (1) or false(0). bool isOpen = true;
Valueless void N/A Represents the absence of a value; used in funtion returns. void My_Function()

Note that the exact memory sizes can vary depending on the system architecture and compiler.
Sizes can be check using the sizeof() operator.


2.Derived Data Types

  • Arrays: A sequential collection of elements of the exact same data type.
    • 			C++ Code 💻

			int numbers[5] = {1, 2, 3, 4, 5};
  • Pointers: Variables that store the memory addresses of another variable instead of a value. 
    • 			C++ Code 💻

			int value = 10;
			int *ptr = &value;  // ptr stores the address of the value
  • Functions: Blocks of code with specific parameter types and return types.
    • 			C++ Code 💻

			int if_eligible()
			{
			   if (age >= 18)
			   {
			   	return 1;
			   }

			   else
			   {
			       return 0;
			   }
			}

3.User-Defined Data Types

These are custom structures that programmers create to handle complex data representations.


  • Structure (struct): Groups related variables of different data types under a single name.
    • 			C++ Code 💻

			struct Student
			{
			   int class;
			   int roll.no;
			   char grade;
			};
  • Class (class): The core of OOP. It binds data (variables) and methods (functions) into a single unit.

  • Union (union): Similar to structures, but all members share the exact same memory location to save space.
