What is if-else statement?

An if-else statement in C++ is a conditional statement used to control the flow of a program based on
specific conditions. It allows the application to make decisions by executing one block of code if a
condition is true, and a different block if it is false.


Basic if-else Syntax

				C++ Code 💻

				if (condition)
				{
				   ...
				}     // this block executes if the condition is true

				else
				{
				   ...
				}     // this block executes if the condition is false

For example:


				C++ Code 💻

				#include<iostream>
				using namespace std;

				int main()
				{
				   int age;

				   cout<<"Enter your age:";
				   cin>>age;

				   if (age >= 18)
				   {
				   	   cout<<"You are an adult";
				   }

				   else
				   {
				   	   cout<<"You are not an adult";
				   }

				   return 0;
				}



3.The if-else  if-else Ladder

When you need to test multiple conditions in sequence, you can chain else if blocks. The program checks
them from top to bottom and runs the block for the first true condition it finds.
For example 


				
				C++ Code 💻


				#include<iostream>
				using namespace std;

				int main()
				{
				   int score = 85;

				   if (score >= 90)
				   {
				   	   cout<<"Grade A";
				   }

				   else if (score >= 80)
				   {
				   	   cout<<"Grade B";
				   }

				   else if (score >= 70)
				   {
				   	   cout<<"Grade C";
				   }

				   else
				   {
				   	   cout<<"Grade F";
				   }

				   return 0;
				}
