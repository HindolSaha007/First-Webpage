What is Loops?

Loops in C++ are control flow structures that allow you to repeatedly execute a block of code.
Instead of writing the same line of code multiple times, loops automate the process based on conditions.

C++ provides four main types of loops, along with two essential control statements to modify their
behaviour. Here we are going to learn only two (for and while) loop.


1.The for Loop (Counter-controlled

Use a for loop when you know exactly how many times you want to execute a block of code.
It groups initialization, condition testing, and updating into single line. 


				
				C++ Code💻

				#include<iostream>
				using namespace std;

				int main()
				{
				   for (int i=0; i<5; i++)
				   {
				   	cout<<i<<" ";
				   }

				   return 0;
				}


The while Loop (Entry-Controlled)

Use a while loop when the number of repetitions is not known in advance. It checks
the condition before entering the loop. If the condition starts as false, the body never runs.


				
				C++ Code 💻

				#include<iostream>
				using namespace std;

				int main()
				{
				   int i = 0;

				   while (i < 5)
				   {
				   	   cout<<i<<" ";
				   	   i++;
				   }

				   return 0;
				}


Note how the while loop actually runs until the given condition gets false.
