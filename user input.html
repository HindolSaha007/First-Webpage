Basic Input Using

In C++ taking user input is primarily handled in the <iostream> library, which provides the standard input stream object cin.
Depending on the type of data (e.g. integer value, single word, or full sentence) either the extraction operator (>>) or the
getline() funtion is used.


The extraction operator (>>) is ideal for reading numbers, single characters, or single words. It automatically converts
the input to match the variable type.



		C++ Code 💻

		#include<iostream>
		using namespace std;

		int main()
		{
		   int age;

		   cout<<"Enter your age: ";
		   cin>>age;
		   cout<<"Your age is: "<<age;

		   return 0;
		}


Check how the age input given by the user, gets stored in the variable "age". Remember to initialize the variable
type (here it is interger (int)).


Chaining Multiple Inputs

Multiple inputs can also be chained by using the >> operator. The user can seperate inputs with spaces ot tab.


		C++ Code💻

		#include<iostream>
		using namespace std;

		int main()
		{
		   int len, breadth, area;

		   cout<<"Enter the length and breadth of the rectangle: ";
		   cin>>len>>breadth;

		   area = len*breadth;

		   cout<<"The area of the rectangle is: "<<area;

		   return 0;
		}


Take a look at how the len and breadth variables are chained together.


Getting a Single Character

To take a single character as an input we use the char type variable.


		
		C++ Code💻

		#include<iostream>
		using namespace std;

		int main()
		{
		   char choice;

		   cout<<"Enter your choice (Y/N): ";
		   cin>>choice;

		   cout<<"Your choice is: "<<choice;

		   return 0;
		}


Notice something we used char variable this time, instead of int which takes a single character as the input.
Another useful variable type is float which takes decimal numbers as input (e.g. 10.20, 80.99).
